# gitesvienne.fr

Site des domaines de mariage (Persine, Montbeil, la Borderie) et des gîtes (Clos de Mélior, Villa d'Elinas) autour de Lusignan.

- `index.html` : la page du site (générée, ne pas modifier à la main)
- `ical.php` : disponibilités lues sur Amenitiz (cache 1 h)
- `contact.php` : formulaire et e-mail de présentation automatique
- `_sources/` : textes, tarifs et générateur (`python3 _sources/build.py` régénère `index.html`)
